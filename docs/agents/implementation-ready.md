# Implementation-ready standard

The implementer can start without a design decision. The spec and the ticket tell:

- **Where**: the files to create, change, and delete, test files included.
- **What**: the public types and signatures, and the IPC commands and DTOs, as code. No function bodies.
- **How**: the approach in a few lines. For example, where the state lives and which mechanism does the work.

The implementer decides all other things.
