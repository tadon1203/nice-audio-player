# Git workflow

- Commit to `main`. Use a branch for a big or risky change.
- Commit message format: `<type>(<scope>): <description>` ([Conventional Commits](https://www.conventionalcommits.org/)).
  - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `chore`.
  - Write the description in the imperative mood, in lowercase, with no period.
  - Mark a breaking change with `!` or a `BREAKING CHANGE:` footer.
